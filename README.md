## 🚀 Características Principales (Features)

Esta PWA (Progressive Web App) disfrazada de sitio estático incluye gatillos psicológicos y técnicos diseñados específicamente para el mercado inmobiliario y turístico:

- **📶 Copiado Mágico de WiFi:** Botón nativo en JavaScript que copia la contraseña al portapapeles con un solo toque.
- **📱 QR Dinámico "Multijugador":** Código QR incrustado en la pantalla para que los acompañantes del huésped principal se conecten escaneando el celular.
- **🗺️ Geolocalización Infalible:** Botones con Deep Linking directos a **Google Maps, Waze y Apple Maps** inyectando coordenadas GPS exactas (evita que los extranjeros se pierdan).
- **📹 Tutoriales en Video Integrados:** Soporte nativo para incrustar YouTube Shorts (9:16) ideales para explicar cerraduras inteligentes, estufas o boilers complicados.
- **📖 Reglamento Colapsable (Acordeón):** Reglas de la casa redactadas con persuasión positiva y estructuradas en etiquetas `<details>` nativas de HTML5 para no saturar la pantalla.
- **💬 Contacto a 1-Clic:** Botón flotante persistente de WhatsApp y marcación telefónica directa (`tel:`) para anfitriones y números de emergencia locales (911, Hospital, Caseta).

## 🎨 Diseño y UX/UI

- **Paleta de Colores "Brisa del Mar":** Tonos tropicales y relajantes adaptados al destino (Riviera Nayarit).
- **Glassmorphism:** Menú superior (Header) con efecto de vidrio esmerilado que emula el ecosistema iOS de Apple.
- **Iconografía Nativa:** Uso exclusivo de SVGs escalables y ligeros (cero dependencias a librerías externas pesadas como FontAwesome).
- **Carga Ultra Rápida:** Al ser archivos estáticos (HTML/CSS/JS), el tiempo de carga es menor a 1 segundo, vital para huéspedes que usan datos móviles en zonas turísticas.
